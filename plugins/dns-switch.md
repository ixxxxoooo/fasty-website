# DNS 切换

快速切换 macOS 网络 DNS 服务器

## 主要功能

- 一键切换 DNS 服务器

## 触发关键词

在搜索框中输入以下任意关键词或拼音首字母即可打开：

`DNS 切换`、`dns`、`域名`、`网络`、`8.8.8.8`、`cloudflare`

## 使用提示

- 首次使用需要网络访问权限。
- 结果可能受本地网络环境影响。
- 按 <kbd>⌘K</kbd> 可查看该插件的更多可用操作。
- 按 <kbd>⌘D</kbd> 可将插件分离为独立窗口。
