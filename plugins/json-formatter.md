# JSON 格式化

JSON 格式化与压缩，支持语法高亮

## 主要功能

- 格式化 / 压缩 / 校验 JSON

## 触发关键词

在搜索框中输入以下任意关键词或拼音首字母即可打开：

`JSON 格式化`、`json`、`格式化`、`format`

## 使用提示

- 支持直接粘贴文本进行转换、格式化或校验。
- 可为常用命令绑定全局快捷键，一键直达。
- 按 <kbd>⌘K</kbd> 可查看该插件的更多可用操作。
- 按 <kbd>⌘D</kbd> 可将插件分离为独立窗口。
