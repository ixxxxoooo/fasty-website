# 系统控制

通过关键词控制 macOS：屏保、废纸篓、锁屏、睡眠、重启、关机、全部弹出；可开关命令并引导自动化权限

## 主要功能

- 管理系统命令开关与自动化权限
- 启动屏幕保护程序
- 在 Finder 中打开废纸篓
- 清空废纸篓（需确认）
- 注销当前用户（需确认）
- 让 Mac 进入睡眠
- 关闭显示器
- 锁定屏幕
- 重启 Mac（需确认）
- 关闭 Mac（需确认）
- 弹出全部可移除磁盘（排除系统盘与 Time Machine）
