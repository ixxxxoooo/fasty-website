# 系统信息

查看 CPU、内存、磁盘、网络等系统信息

## 主要功能

- CPU / 内存 / 磁盘 / 网络概览

## 触发关键词

在搜索框中输入以下任意关键词或拼音首字母即可打开：

`系统信息`、`系统`、`system`、`信息`、`硬件`

## 使用提示

- 涉及系统操作时请谨慎，执行前确认目标。
- 部分能力需要辅助功能等系统授权。
- 按 <kbd>⌘K</kbd> 可查看该插件的更多可用操作。
- 按 <kbd>⌘D</kbd> 可将插件分离为独立窗口。
