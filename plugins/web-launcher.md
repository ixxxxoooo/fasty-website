# 网页快开

配置搜索引擎与直达链接；选中文字 + 快捷键即可搜索

## 主要功能

- 管理搜索引擎与快捷链接

## 触发关键词

在搜索框中输入以下任意关键词或拼音首字母即可打开：

`网页快开`、`网页`、`网站`、`快开`、`搜索`、`web`、`url`、`google`、`百度`

## 使用提示

- 输入插件名称、功能关键词或拼音首字母即可快速找到。
- 在选中文本后唤起 Fasty，可直接把内容带入插件处理。
- 按 <kbd>⌘K</kbd> 可查看该插件的更多可用操作。
- 按 <kbd>⌘D</kbd> 可将插件分离为独立窗口。

## 所需权限

该插件在使用时可能需要以下系统能力，首次调用时按提示授权即可：

- 执行系统命令
