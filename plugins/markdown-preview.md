# Markdown 预览

实时 Markdown 编辑与预览，支持 GFM 语法

## 主要功能

- 编辑并实时预览 Markdown

## 触发关键词

在搜索框中输入以下任意关键词或拼音首字母即可打开：

`Markdown 预览`、`markdown`、`md`、`预览`

## 使用提示

- 支持直接粘贴文本进行转换、格式化或校验。
- 可为常用命令绑定全局快捷键，一键直达。
- 按 <kbd>⌘K</kbd> 可查看该插件的更多可用操作。
- 按 <kbd>⌘D</kbd> 可将插件分离为独立窗口。

## 所需权限

该插件在使用时可能需要以下系统能力，首次调用时按提示授权即可：

- 读取剪贴板
- 写入剪贴板
