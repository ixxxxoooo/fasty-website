# 快捷键

以下为默认快捷键，可在「设置 → 快捷键」中自定义。

## 全局

| 快捷键 | 功能 |
| --- | --- |
| <kbd>⌥Space</kbd> | 唤起 / 隐藏 Fasty |
| <kbd>Esc</kbd> | 清空输入；输入为空时隐藏窗口 |

## 搜索与导航

| 快捷键 | 功能 |
| --- | --- |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 切换选中的结果 |
| <kbd>Enter</kbd> | 执行选中的命令 |
| <kbd>⌘K</kbd> | 打开当前条目的操作面板 |
| <kbd>⌘D</kbd> | 将当前插件分离为独立窗口 |
| <kbd>⌘,</kbd> | 打开设置 |

## 通用编辑

| 快捷键 | 功能 |
| --- | --- |
| <kbd>⌘C</kbd> / <kbd>⌘V</kbd> / <kbd>⌘A</kbd> | 复制 / 粘贴 / 全选（在输入与数据区域可用） |

> 提示：为常驻应用添加全局快捷键后，无需先唤起 Fasty 也能一键直达。
