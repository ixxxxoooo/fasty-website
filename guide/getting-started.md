# 快速开始

Fasty 是面向 macOS 的统一效率入口。它把「找东西」和「做事情」合并进同一个搜索框：

> **Search → Select → Execute**

不再需要在不同应用之间来回切换，也不用记住每个功能的入口位置。

## 三步上手

### 1. 唤起

按下默认快捷键 <kbd>⌥Space</kbd>，Fasty 会出现在屏幕中央并自动聚焦输入框。松开后如果切换到别的应用，它会自动隐藏。

### 2. 查找

直接输入关键词即可：

- 输入 `计算`、`jisuan` 或 `js` 都能找到「计算稿纸」；
- 输入应用名可以快速启动或切换到应用；
- 输入文件名或路径片段可以搜索本地文件；
- 输入网址关键词可直接打开网页或执行搜索。

### 3. 执行

- 用 <kbd>↑</kbd> <kbd>↓</kbd> 移动选中项；
- 按 <kbd>Enter</kbd> 执行选中的命令；
- 按 <kbd>Esc</kbd> 清空输入，再按一次隐藏窗口。

## 认识界面

- **搜索框** — 输入区，支持粘贴图片直接触发对应操作。
- **结果列表** — 展示匹配的插件、应用、文件与设置，右侧标注来源。
- **操作面板** — 按 <kbd>⌘K</kbd> 展开当前条目的更多可用操作。
